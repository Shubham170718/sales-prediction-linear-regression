This project demonstrates a complete Machine Learning workflow using the Advertising dataset to predict Sales based on marketing budget spent on TV, Radio, and Newspaper channels.

It includes:

  A Jupyter Notebook for model training

  A Streamlit Web App for real-time predictions

Project Features:

a. Model Training (Notebook):

   1. Load and analyze dataset

   2. Perform exploratory data analysis (EDA)

   3. Train a Linear Regression model

   4. Evaluate model performance

   5. Save the trained model (linear_regression_model.pkl)

b. Model Deployment (Streamlit App):

   1. Accepts advertising budget inputs

   2. Uses trained model to predict sales

   3. Real-time prediction displayed on screen

   4. Simple and user-friendly UI


Model Training Workflow (Notebook):

The notebook linear_regression L6.ipynb performs these steps:

  1️. Import libraries & dataset
  
  2️. Exploratory Data Analysis
  
  3️. Train-Test Split
  
  4️. Train Linear Regression Model
  
  5️. Evaluate Performance
  
  6️. Save Model Using Pickle
